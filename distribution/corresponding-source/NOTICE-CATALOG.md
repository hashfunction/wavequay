# Original source and notice catalog

`source-inputs.json` indexes 40 preferred-source archives and 532 unchanged original notices. It is a source input catalog, not an installed qualification or source-publication receipt. Package inclusion, current Microsoft runtime provenance and the final independent release gate remain separate integration work.

The 31 actually consumed Muse dependency owners have 33 source parts (VST3 uses three parts). Each part retains the current resolver's original URL/hash, exact owned recipe inventory, complete public preferred-source archive URL/hash/size and original notice member hashes. The other seven sources are the five actual Qt modules, Mesa 11.2.2 and LLVM 3.6.2. Qt's original binary/source inventory comparison is documented in `SOURCE-COMPARISON.md`. Mesa and LLVM retain their historical permissive notices; this catalog does not reconstruct Qt's historical Mesa build recipe.

The 300 archive notices include complete license files, original incorporated-code notices and the license files referenced by the actual Qt Windows binary SPDX attribution declarations. Original attribution JSON is retained as bytes, including upstream literal newlines. SQLite and PFFFT retain complete original leading license comments with full source-member hashes and explicit byte ranges. FreeType includes its original license-choice text, FTL and GPL terms.

The 232 repository notices preserve the original application and Muse licenses, Nyquist, KDDockWidgets, six Kors libraries, SG14, PortMixer, FluidSynth, moodycamel and stb notices. The moodycamel queue retains its complete simplified BSD notice; the blocking queue copyright and Jeff Preshing semaphore terms remain separately indexed. The FFmpeg integration supplies vendored headers for versions 4–8. Their original copyright/license comments and the pinned Muse header provenance README are included. These headers are in the exact Muse source checkout; this is not a claim that an FFmpeg runtime DLL is shipped. The observed runtime inventory contains no FFmpeg DLL.

Notice files carry `-text` Git attributes so a Windows checkout cannot rewrite the packaged bytes. For explicitly marked Muse source members, the current repository comparison can report a lossless LF-to-CRLF checkout expansion. It requires the original complete member hash after precisely reversing that expansion; mixed/lone CR, arbitrary whitespace changes and modified source/license text fail. Original packaged notices are never normalized.

`distribution/msix/source_catalog.py` requires the exact consumed source set, current recipe hashes, the complete indexed notice tree and current application/vendored source members. `verify_archives` additionally checks every supplied complete archive's exact size/hash and reads its selected regular notice members without extraction or execution. Missing, duplicate, altered, linked, oversized and untracked inputs fail. Both helpers explicitly retain `sourceLicenseClosure: false`: URLs and notice bytes alone do not establish installed success or complete release approval.

Local verification on 2026-09-12 uses the current production CMake recorder against the 31 owners actually consumed in run 34697625639. Six regression cases cover that current source replay, full archive/member matching, notice loss/substitution/addition, owner/source/recipe mutation, credentialed URLs, unsafe aliases, typed ranges and the restricted Windows checkout comparison. The original archives are kept outside Git; no binary or source archive is copied into this source repository.

The production reader also completed all 40 actual preferred-source archive comparisons locally: 33 consumed source parts and all 532 notices passed, totaling 2,196,038 unchanged notice bytes. The Git index was independently compared with each original notice blob so checkout filters cannot silently rewrite the result; the historically ignored `COPYING.LIB` license is explicitly tracked. All 23 source/catalog/archive regression cases pass. These observations were made on macOS and do not replace the pending native Windows consumer, MSIX or source-publication gates.
