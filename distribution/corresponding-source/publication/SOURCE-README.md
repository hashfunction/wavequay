# WaveWeft component sources

This source-only release provides 40 unchanged preferred-source archives used by the WaveWeft Windows build and its supporting native dependencies, with the original copyright and license notices retained inside each archive. The SHA-256 manifest gives the precise source versions, origins and download links.

The accompanying source-inputs.json records the exact build recipes and 532 original component notices. The matching application source and Windows build scripts are in this repository. This release does not contain a Windows app package and does not claim a completed installed workflow or Microsoft Store approval.

The Qt 6.11.2 source archives were compared with the original Qt binary source inventories. Historical Mesa and LLVM preferred sources retain their original notices; this is not a reproducible-build claim. Microsoft runtime components remain separately licensed and are not represented as open-source code by this collection.

Product, source and support information: https://waveweft.trieflow.com/source
