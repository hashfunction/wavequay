  30-second network read timeout. It uses no authentication token or mutable ref.
- `store_export.collect` requires current source/run/attempt, strict typed normal
  flags, source closure, both fixed regenerated package records/containers and

  start receipt and seven GUI/claim/display/watchdog snapshots by exact bytes.
  It independently replays the existing GUI/screenshot/flow checks, all ten

  the eight filename/export/recipe text confirmations and both loaded-module
  observations. The recipe choice supports only the source-defined bounded
  ListItem navigation; neither missing input nor an extra action is accepted.
- The original `consumer_audio.finalize` remains the independent parser of the
  actual WAV, SQLite and recipe files before cleanup. `oracle_records` validates
  its complete typed values and exact original file/profile/registry snapshot
  hashes, original CC0 composition, both reversed PCM records, saved project and
  unique recipe. It requires all seven claimed profile roots, both registry
  roots and the exact package owner snapshot/uninstall delegation. The exporter
  explicitly records `deletedFilesReparsed=false`; no raw audio/project/profile
  retention or upload is added.
- The workflow now runs source comparison, two separate installed qualifications
  and the independent exporter after the existing normal staged qualification.
  Only complete success uploads exactly the untouched unsigned
  `WaveWeft_1.0.1.0_x64.msix` and `store-export.json`. A package changed after

  exact JSON/PNG/owned logs and contain no package/private signing payload.
